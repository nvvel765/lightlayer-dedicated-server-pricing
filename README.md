## 常见问题

**独立服务器和云服务器差在哪？**
独服是整台物理机独享，CPU、内存、硬盘不跟别人抢，性能可预期，适合长期跑的重负载业务。云服务器开通快、能弹性升降配，同样的钱买到的算力少一些。LightLayer 洛杉矶独服 $40、云服务器 $4 起，十倍价差买的就是这份独享。

**100M 不限流量和 1Gbps 限流量怎么选？**
看你的流量曲线。持续跑满的下载、代理、视频转码类业务，不限流量更省心，100Mbps 跑满一个月是 30TB 量级。突发型业务比如网站访问、API 调用，1Gbps 端口加 1TB 流量包更合适，平时端口跑不满，高峰时能 burst 上去。

**CN2 线路 130–160ms 是正常水平吗？**
这是华纳云页面对其洛杉矶 CN2 GIA 线路给的数字（该页未标注更新时间）。洛杉矶到国内骨干的往返延迟在这个区间属于常见水平，实际体验还取决于晚高峰是否拥塞。GigeNET 公布的洛杉矶到东京约 110ms、悉尼 145ms，可以用来对照亚太方向的预期。

**开通要多久？**
LightLayer 没有公开承诺。行业里现货普遍在 1 小时到 1 个工作日之间，定制配置会拉到一周。

**香港机房能解锁流媒体吗？**
第三方评测指出 LightLayer 香港机房的 IP 不是原生 IP，Netflix、Disney+ 这类服务可能受限。建站、API、普通网络应用不受影响。
